# Подбор балки и экспорт в КОМПАС-3D

Локальное Windows-приложение на Python для подбора сечения балки по прочности, жёсткости, массе и коэффициенту запаса. Лучшие варианты можно экспортировать в КОМПАС-3D через API7; если COM-сервер недоступен, программа создаёт JSON mock-файлы с параметрами модели.

## Возможности

- GUI на `tkinter` для ввода длины балки, материала, схемы закрепления, нагрузки и ограничений.
- Подбор параметрических сечений: прямоугольник, квадрат, сплошной круг, круглая труба.
- Расчёт 1D балки по модели Euler-Bernoulli FEM.
- Проверка максимального напряжения, максимального прогиба и минимального коэффициента запаса.
- Ранжирование результатов по минимальной массе или максимальному запасу прочности.
- Сохранение отчётов, логов и моделей в папку `output/`.
- Live-экспорт `.m3d` в КОМПАС-3D при наличии `pywin32` и установленного КОМПАС-3D.

## Структура проекта

- `main.py` - точка входа для запуска GUI.
- `beam_optimizer/gui.py` - интерфейс, валидация пользовательского ввода и запуск workflow.
- `beam_optimizer/models.py` - dataclass-модели предметной области.
- `beam_optimizer/materials.py` - справочник материалов.
- `beam_optimizer/sections.py` - генерация вариантов сечений и расчёт геометрических характеристик.
- `beam_optimizer/solver.py` - расчёт балки методом конечных элементов.
- `beam_optimizer/optimizer.py` - фильтрация, проверка ограничений и ранжирование вариантов.
- `beam_optimizer/integrations.py` - адаптер КОМПАС-3D API7 и fallback mock-экспорт.
- `beam_optimizer/reporting.py` - создание папок `output/`, логирование и JSON-отчёт.
- `tests/test_optimizer.py` - минимальные regression-тесты расчётной части.

## Требования

- Windows.
- Python 3.11 или новее.
- Для обычного расчёта внешние зависимости не нужны.
- Для реального экспорта в КОМПАС-3D нужен установленный КОМПАС-3D и пакет `pywin32`.

## Установка

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
```

Если нужен live-экспорт в КОМПАС:

```powershell
python -m pip install -e ".[kompas]"
```

## Запуск

```powershell
python main.py
```

После установки пакета можно запускать через console script:

```powershell
beam-kompas-optimizer
```

## Как пользоваться

1. Выберите тип сечения, материал, схему закрепления и тип нагрузки.
2. Задайте диапазон перебора размеров в миллиметрах.
3. Укажите ограничения: максимальное напряжение, максимальный прогиб и минимальный коэффициент запаса.
4. Выберите критерий ранжирования: минимальная масса или максимальный запас прочности.
5. Оставьте включённым создание модели КОМПАС, если установлен КОМПАС-3D и доступен COM API7.
6. Нажмите `Запустить подбор`.

Результаты отображаются в таблице GUI. Детали выбранного варианта показываются в нижней текстовой области.

## Выходные данные

При каждом запуске создаётся структура:

```text
output/
  logs/
    beam_optimizer.log
  models/
    *.m3d или *.kompas.json
  reports/
    run_report.json
```

`run_report.json` содержит входные параметры, количество сгенерированных вариантов, число прошедших ограничения и выбранные результаты.

## Проверка проекта

```powershell
python -m compileall .
python -m unittest
```

В текущем окружении важно запускать настоящий установленный Python, а не Microsoft Store alias. Если команда `python` не работает, используйте полный путь к интерпретатору или исправьте `PATH`.
